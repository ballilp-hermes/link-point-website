Hermes — Private Personal Assistant

Single-user automation for one Google Account · operated by Link Point Trading (Hong Kong) Limited

What this application is

Hermes is a private desktop automation tool. It runs on its owner's own Mac and performs work the owner asks for directly — for example scheduling a meeting on the owner's calendar, triaging an inbox, or updating one of the owner's spreadsheets.

It is not a public product. There is no sign-up, no dashboard, no multi-user service, and it is not distributed to anyone. It has exactly one user: the person who owns the Google Account that authorises it.

What it does with Google data

  • Calendar — lists and creates events on the owner's own calendar at the owner's request.
  • Gmail — reads, searches, labels, drafts and sends mail only when the owner instructs it to. Nothing is sent without the owner's approval of that specific message.
  • Drive, Sheets, Docs — locates, reads and edits the owner's own files to produce requested documents and reports.
  • Contacts — read-only, used to resolve a name to an email address.

Access is granted through Google's standard OAuth 2.0 consent screen, scope by scope. The owner can revoke it at any time.

What it never does: no advertising, no profiling, no resale of data, no lending or creditworthiness determinations, no training of generalised models on Google user data.

Where the data lives

OAuth tokens and working files stay on the owner's own machine with owner-only file permissions. There is no remote application server holding Google user data.
